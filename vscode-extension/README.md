# AI Code Review Agent - VS Code Extension

## Features
- Real-time analysis on file save
- Inline diagnostics with severity colors
- CodeLens action for Jira sync
- Status bar summary of analysis results
- Configuration selector (`strict`, `balanced`, `fast`)
- WebView for detailed result summary

## Commands
- `AI Code Review: Analyze Current File`
- `AI Code Review: Sync Issues to Jira`
- `AI Code Review: Open Results`
